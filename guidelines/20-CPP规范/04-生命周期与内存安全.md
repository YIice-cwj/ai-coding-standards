## 1. 构造、移动语义与返回值优化 (NRVO)

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-CTOR]**  | MUST | 单参构造函数强制标 `explicit`；虚函数重写标 `override`（禁与 `virtual` 混写） | 隐式类型转换；漏标 `override` |
| **[R-CPP-RULE]**  | MUST | 优先 **Rule of 0**（智能指针/容器管理）；持有底层原生句柄时严格 **Rule of 5** | 手动写析构却漏写拷贝/移动控制函数 |
| **[R-CPP-MOV-NOEX]**| MUST| 移动构造与移动赋值**必须标记 `noexcept`**（防 `vector` 扩容退化为深拷贝） | 移动操作未标记 `noexcept` |
| **[R-CPP-NRVO]**  | MUST | 返回局部对象直接按值返回；利用 NRVO 零拷贝 | **严禁 `return std::move(p);`**（阻断 NRVO，引发多余移动） |

```cpp
// ❌ 错误：阻止编译器 NRVO 优化
payload_t make_payload() { payload_t p; p.init(); return std::move(p); }

// ✅ 正确：NRVO 零拷贝返回
payload_t make_payload() { payload_t p; p.init(); return p; }
```

## 2. 内存管理与资源安全

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-SMART]** | MUST | 绝无裸 `new`/`delete`；独占首选 `std::make_unique`；共享用 `std::make_shared` | 裸指针掌管生命周期；忘记释放造成内存泄漏 |
| **[R-CPP-CYCLE]** | MUST | 共享引用打破环形依赖强制使用 `std::weak_ptr` | `shared_ptr` 循环引用导致对象永久泄漏 |
| **[R-CPP-CONT]**  | MUST | 顺序容器默认首选 `std::vector`，已知容量前先调用 `reserve()` | **严禁默认使用 `std::list`**（节点离散导致缓存不命中） |
| **[R-CPP-VIEW]**  | MUST | `std::string_view` 与 `std::span` 绝不绑定临时对象；类成员变量严禁使用 view | 返回局部临时对象的 view 导致悬垂引用；类成员持 view |
| **[R-CPP-UNSAFE]**| MUST | 严禁 `strcpy`, `sprintf` 等危险 C 函数；统一用 `std::string`, `std::format` | 使用无边界溢出风险的废弃 C 字符串函数 |
