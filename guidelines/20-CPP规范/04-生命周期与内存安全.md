## 8. 构造、移动语义与生命周期

- **构造与虚函数**：单参构造函数必须标记 `explicit`；成员变量声明处直接默认初始化；虚函数重写显式标记 `override`（禁止同时写 `virtual` 和 `override`）；观察函数严格标记 `const`。
- **特殊成员策略 (Rule of 0 / Rule of 5)**：
  - **优先 Rule of 0**：使用智能指针和容器，不手动声明析构与拷贝/移动操作，交由编译器默认合成。
  - **严格 Rule of 5**：持有外部原生句柄而自定义任意一个特殊成员时，**必须显式声明全部 5 个**（`= default`, `= delete` 或自定义实现）。
- **移动与 noexcept**：移动构造与移动赋值**必须标记 `noexcept`**（否则 `std::vector` 扩容降级为深拷贝）；不抛异常函数标 `noexcept`。

## 10. 性能与最佳实践

### 10.1 返回值优化 (NRVO)
返回局部对象时直接按值返回；**严禁使用 `return std::move(p);`**（会阻断 NRVO，反而强制引发额外移动构造）：

```cpp
// ✅ 正确：NRVO 零拷贝
payload_t make_payload() {
    payload_t p;
    p.init();
    return p;
}

// ❌ 错误：禁用 NRVO
payload_t make_payload() {
    payload_t p;
    p.init();
    return std::move(p);
}
```

### 10.2 容器最佳实践
- 已知大小必须在填充前调用 `reserve()`；优先使用 `emplace_back` / `emplace` 原位构造。
- 顺序容器默认首选 `std::vector`，**严禁默认使用 `std::list`**（节点离散分配导致高缓存不命中与内存膨胀）。

## 14. 内存管理与资源安全

- **禁止裸 `new` 与裸 `delete`**：独占所有权用 `std::unique_ptr`（`std::make_unique`）；共享用 `std::shared_ptr`（`std::make_shared`）；循环引用用 `std::weak_ptr` 打破。
- **智能指针决策**：
  ```
  需要共享所有权？
  ├─ 是 ──► 存在循环引用风险？
  │          ├─ 是 ──► std::weak_ptr<T> (观察者，无所有权)
  │          └─ 否 ──► std::shared_ptr<T> (std::make_shared)
  └─ 否 ──► 需要堆生命周期？
             ├─ 是 ──► std::unique_ptr<T> (std::make_unique)
             └─ 否 ──► 优先栈对象 / 值语义传递
  ```

## 16. 安全编码规范

- **危险函数替代**：严禁 `strcpy`, `strcat`, `sprintf`, `strncpy`；优先使用 `std::string`, `std::string_view`, `std::format` (C++20) 或 `snprintf`；随机数使用 `<random>` 的 `std::random_device`。
- **视图类型生命周期**：`std::string_view` 与 `std::span` 均为非所有权视图，**严禁返回局部临时对象的视图**；类成员变量禁止使用 `std::string_view`（必须使用 `std::string`）；连续内存参数使用 `std::span<const T>` 替代 `const T* + size_t`。
