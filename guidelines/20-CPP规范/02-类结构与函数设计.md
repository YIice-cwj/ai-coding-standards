## 4. 类结构规范（接口优先 15 层布局）

类声明内部必须严格按以下 15 层顺序组织，坚持“公开接口优先 (Interface-First)”：

```cpp
class example_t {
public:    // 1. public 类型定义 (using / enum class)
protected: // 2. protected 类型定义
private:   // 3. private 类型定义
public:    // 4. public 常量 (static constexpr)
protected: // 5. protected 常量
private:   // 6. private 常量
public:    // 7. public 成员函数 (构造/析构/核心业务接口 - 接口对外优先展现)
protected: // 8. protected 成员函数
private:   // 9. private 成员函数 (带 _ 后缀)
public:    // 10. public 静态函数
protected: // 11. protected 静态函数
private:   // 12. private 静态函数
private:   // 13. private 成员变量与静态变量 (带 _ 后缀，实现细节封装于底)
protected: // 14. protected 成员变量与静态变量
public:    // 15. public 成员变量 (纯 POD struct 除外，普通 class 极力避免)
};
```
- **实现顺序对齐**：源文件（`.cc`）中的函数实现顺序，**必须与头文件类声明顺序 1:1 严格对齐**。
- **单文件单类**：一个 `.h` 只承载一个类，具体实现（如有）置于同名 `.cc`；纯类型聚合头（如 `types.h`）仅允许无行为类型、别名与枚举；嵌套类仅限内部实现细节，严禁借嵌套规避单文件单类。
- **职责边界**：类只做职责内的事，UI 类只展示与派发意图，不得直接修改业务数据或持久化（详见 [R-ARCH-CLASS](../10-通用代码规范/02-架构健壮性与工程安全.md#单文件单类与职责边界-r-arch-class)）。
- **头文件依赖**：统一使用 `#pragma once`；指针/引用依赖优先使用前向声明。

## 5. 函数设计与必要防御原则

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-LEN]**   | MUST | 函数长度建议 $\le 50$ 行；形参建议 $\le 4$ 个；**禁止非 const 引用输出参数**（通过返回值返回） | 滥用输出参数；巨型函数 |
| **[R-CPP-GUARD]** | MUST | Guard Clause 提前返回；主流程线性一路向下；嵌套深度 $\le 3$ 层 | 深层多层嵌套 `if-else` |
| **[R-CPP-DEF-REF]**| MUST | 语法层面保证引用必有效，**严禁判断 `&param == nullptr`** | 针对引用进行空指针防御 |
| **[R-CPP-DEF-THIS]**| MUST | 成员函数内**严禁判断 `this == nullptr`**（属于标准未定义行为 UB） | 成员函数内部判断 this 非空 |
| **[R-CPP-DEF-NEW]**| MUST | 默认 `new` / `make_unique` 失败抛 `bad_alloc`，**严禁在其后判断是否为 `nullptr`** | 在 `make_unique` 后检查判空 |
| **[R-CPP-DEF-INV]**| MUST | 信任构造函数与内部状态机已确立的不变式，内部私有调用不层层设卡 | 内部链路为 0.1% 极小概率臆想设卡 |

```cpp
// ❌ 反例：神经过敏过度防御（严重违反 B4）
bool inventory_t::add_item(const item_t& item) {
    if (this == nullptr || &item == nullptr) return false; // 错！语法保证不可能为空
    if (capacity_ <= 0 || item.id() <= 0) return false;   // 错！构造已保证
    if (items_.size() >= capacity_) return false;
    items_.push_back(item);
    return true;
}

// ✅ 正例：像资深人类工程师一样直接清晰，信任契约
bool inventory_t::add_item(const item_t& item) {
    if (items_.size() >= capacity_) { return false; }
    items_.push_back(item);
    return true;
}
```
