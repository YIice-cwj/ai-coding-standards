## 1. 错误处理与日志规范

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-ERR-RET]**| MUST | 主业务链路首选 `std::optional` / `std::expected` / 状态码返回 | 内部频繁依赖昂贵的异常机制控制普通控制流 |
| **[R-CPP-ERR-CTDT]**| MUST| 构造/析构函数内严禁抛出异常（构造失败改用工厂方法返回 expected） | 析构函数抛出异常直接触发 `std::terminate` |
| **[R-CPP-ERR-CTCH]**| MUST| 严禁裸 `catch(...)` 吞异常；精确捕获具体派生异常类型 | 空 catch 掩盖故障使错误蔓延 |
| **[R-CPP-LOG]**    | MUST | 统一结构化日志库，包含 Trace ID 与上下文；高频循环禁打日志 | 生产环境裸用 `std::cout` 或 `printf`；明文打印机密 |

## 2. 并发、线程安全与宏规范

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-CONC-LOCK]**| MUST| 互斥锁必须使用 RAII 管理器（`std::scoped_lock` / `std::unique_lock`） | 手动调用 `.lock()`/`.unlock()`；持锁期间执行耗时 I/O |
| **[R-CPP-CONC-DEAD]**| MUST| 多锁同时获取强制使用 `std::scoped_lock`；禁止 `std::recursive_mutex` | 嵌套乱序加锁引发死锁；依赖递归锁掩盖设计缺陷 |
| **[R-CPP-CONC-THRD]**| MUST| 优先使用 `std::jthread`（析构自动 join 与 stop_token） | C++17 `std::thread` 析构前漏写 `join()` 触发崩溃 |
| **[R-CPP-CONC-WAIT]**| MUST| 条件变量必须使用带谓词的 `cv.wait(lk, [&]{ return ready; })` | 裸 `cv.wait(lk)`（未防御虚假唤醒 Spurious Wakeup） |
| **[R-CPP-MACRO]**    | MUST| 优先使用 `constexpr` 常量与内联函数；多语句宏必须用 `do { ... } while(0)` | 宏命名小写；宏拼接模拟模板 |
| **[R-CPP-BUILD-TEST]**| MUST| Modern CMake 开启 `-Wall -Wextra -Werror`；异步测试**严禁 `sleep_for` 盲等** | 测试用 sleep 盲等（违反真测试契约 B5） |
