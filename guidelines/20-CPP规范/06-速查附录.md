## 附录 B：C++ 编码高频自检对照表

| 检查维度 | 合规要求 | 常见反模式拦截 |
|---|---|---|
| **空指针判定** | 使用 `nullptr` | 出现 `NULL` 或字面量 `0` |
| **单参构造** | 声明 `explicit` | 隐式转换构造导致偶发类型转换缺陷 |
| **虚函数重写** | 显式标注 `override` | 漏标 `override` 导致签名变更时虚函数失效 |
| **只读成员** | 观察方法全标注 `const` | 成员函数不改状态却漏加 `const` |
| **移动操作** | 移动构造与移动赋值标 `noexcept` | 漏标导致 `vector` 扩容退化为深拷贝 |
| **返回值优化** | 直接按值返回局部变量 | 多余写 `return std::move(p);` 阻断 NRVO |
| **视图生命周期**| view 绝不绑定临时对象，类成员不用 view | 返回局部临时变量 view 导致悬垂内存 |
| **智能指针** | 绝无裸 new/delete，全用 make_unique/shared | 裸 `delete ptr;` 或直接 `new` 赋值 |
| **泛型别名** | 模板类提供 `value_type`，使用 `using` | 接口处直接裸写 `T`，或使用旧式 `typedef` |
| **控制流与防御**| Guard Clause 提前返回；内部链路信任契约 | 多层嵌套 `if`；对引用/this 判断非空 (B4) |
