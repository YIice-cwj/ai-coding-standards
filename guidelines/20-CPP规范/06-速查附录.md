## 附录 A：容器选择决策树

```
需要存储键值对？
├─ 是 ──► 要求按键有序遍历？
│          ├─ 是 ──► std::map / std::set (红黑树，O(log N))
│          └─ 否 ──► std::unordered_map / std::unordered_set (哈希表，平均 O(1))
└─ 否 ──► 顺序线性容器：
           ├─ 编译期固定大小？ ──► std::array (栈分配，零额外开销)
           └─ 动态大小：
                ├─ 首尾两端高效插入/弹出？ ──► std::deque (双端队列)
                └─ 默认通用场景 ──► std::vector (连续内存、缓存局部性最佳)
```
> **注意**：除极特殊的大序列中间节点拆拼且无需随机访问外，**严禁默认使用 `std::list`**。

## 附录 B：C++ 编码高频自检对照表

| 检查维度 | 合规要求 | 常见反模式拦截 |
|---|---|---|
| **空指针** | 使用 `nullptr` | 出现 `NULL` 或字面量 `0` |
| **单参构造** | 声明 `explicit` | 隐式转换构造导致偶发类型转换 bug |
| **虚函数重写** | 显式标注 `override` | 漏标 `override` 导致签名变更时虚函数失效 |
| **常量修饰** | 观察方法全标注 `const` | 成员函数不改状态却漏加 `const` |
| **移动操作** | 移动构造与移动赋值标 `noexcept` | 漏标导致 `vector` 扩容退化为深拷贝 |
| **返回值优化** | 直接按值返回局部变量 | 多余写 `return std::move(p);` 阻断 NRVO |
| **视图生命周期** | view 绝不绑定临时对象，类成员不用 view | 返回局部变量 view 导致悬垂内存 |
| **资源安全** | 绝无裸 new/delete，全用 make_unique/shared | 出现裸 `delete ptr;` 或直接 `new` 赋值 |
| **类型别名** | 模板类提供 `value_type`，使用 `using` | 模板内满屏直接裸写 `T`，或用 `typedef` |
| **控制流** | 提前返回，严禁过度防御（非必死不判断） | 多层嵌套 `if`；对引用/this 重复判断；为 0.1% 极小概率设卡 |
