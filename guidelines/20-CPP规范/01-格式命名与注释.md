**所属域**: 20-CPP规范  **域版本**: 6.6.0  **日期**: 2026-10-21  **语言**: C++20 / C++23 (最低兼容 C++17)

## 1. 代码格式与排版

- **缩进与大括号**：4 空格缩进（严禁 Tab）；大括号与关键字同行（K&R 风格），禁止大括号单独占行。
- **文件编码与换行**：UTF-8 无 BOM 编码，统一使用 LF（`\n`）换行符，严禁 CRLF。
- **头文件引用顺序**（自顶向下，组间空行分隔）：
  1. 对应头文件（如 `foo.cc` 优先 `#include "foo.h"`）
  2. C 标准库（`<cstddef>`, `<cstdint>`）
  3. C++ 标准库（`<vector>`, `<string>`, `<memory>`）
  4. 第三方库（`<boost/...>`, `<fmt/...>`）
  5. 项目内部头文件（`"core/manager.h"`）

## 2. 命名规范

> **项目优先原则**：进入已有代码库先推断既有命名风格保持一致；新项目未约定时遵循本章规范。

| 类型分类 | 命名规则 | 正确示例 | 错误示例 |
|---|---|---|---|
| **类 / 结构体** | 小写下划线 + `_t` | `task_manager_t`, `user_data_t` | `TaskManager`, `tagUserData` |
| **接口类** | `i_` + 小写下划线 + `_t` (必含虚析构) | `i_network_service_t` | `INetworkService`, `network_service` |
| **枚举类** | `enum class` + `_t` | `enum class state_t { idle, running };` | 裸 `enum State { IDLE };` |
| **类型别名** | `using ... = ..._t` | `using id_t = std::uint64_t;` | `typedef uint64_t id_t;` |
| **局部 / 形参** | 小写下划线 | `user_id`, `is_active` | `userId`, `bActive` |
| **成员变量** | 私有/保护带单下划线 `_` 后缀 | `name_`, `retry_count_` | `_name`, `m_name` |
| **成员函数** | 小写下划线（私有建议 `_` 结尾） | `calc_total()`, `init_internal_()` | `__init()`（保留字UB） |
| **常量 / 全局** | 常量全大写；全局加 `global_` 前缀 | `MAX_BUFFER_SIZE`, `global_config` | `kMaxBuffer` |
| **命名空间** | 小写下划线 | `namespace core::net` | `namespace CoreNet` |

## 3. 注释规范与函数内部零注释

> **准则 SSOT**：函数体内零业务注释、注释纯粹性见 [行为规范 · Stage 3](../00-行为规范/01-核心铁律与五阶执行模型.md#stage-3-极简实现与最小变更)。

- 函数上方必须使用 `/** */` Doxygen 格式文档注释，说明功能、参数、返回值及异常安全。
- **唯一例外**：静态分析/编译器抑制指令（`// NOLINT`、`/* fallthrough */`）。
- 函数体内需要解释性注释才能看懂时，说明违反单一职责，必须拆分为更小粒度的子函数。

**正例**：
```cpp
/**
 * @brief 计算用户综合评分
 * @param user 待计算的用户数据结构体
 * @return 综合折算后的最终得分
 *
 * 思路：基础积分 + (连续活跃天数 * 每日加成) - (违规次数 * 扣分权重)
 */
int calc_score(const user_t& user) {
    const int base = user.base_score;
    const int bonus = user.active_days * BONUS_PER_DAY;
    const int penalty = user.violations * PENALTY;
    return base + bonus - penalty;
}
```

**反例**：
```cpp
int calc_score(const user_t& user) {
    int base = user.base_score;
    int bonus = user.active_days * BONUS_PER_DAY;  // 活跃天数加成（错！禁行内注释）
    int penalty = user.violations * PENALTY;       // 扣除惩罚（错！禁行内注释）
    return base + bonus - penalty;                  // 错！废话注释
}
```
