## 1. 格式排版与头文件顺序
- **基础格式**：4 空格缩进（严禁 Tab）；K&R 大括号同行；UTF-8 无 BOM + LF (`\n`)。
- **Include 顺序**（自顶向下，组间空行）：
  1. 对应头文件（`#include "foo.h"`）
  2. C 标准库（`<cstddef>`, `<cstdint>`）
  3. C++ 标准库（`<vector>`, `<string>`, `<memory>`）
  4. 三方库（`<boost/...>`, `<fmt/...>`）
  5. 项目内部头文件（`"core/manager.h"`）

## 2. 命名规则对照表

| 类型分类 | 命名规则 | 正确示例 | 严禁反模式 (DON'T) |
|---|---|---|---|
| **类 / 结构体** | 小写下划线 + `_t` | `task_manager_t`, `user_data_t` | `TaskManager`, `tagUserData` |
| **接口类** | `i_` + 小写下划线 + `_t` (必含虚析构) | `i_network_service_t` | `INetworkService`, `network_service` |
| **枚举类** | `enum class` + `_t` | `enum class state_t { idle, running };` | 裸 `enum State { IDLE };` |
| **类型别名** | `using ... = ..._t` | `using id_t = std::uint64_t;` | `typedef uint64_t id_t;` |
| **局部 / 形参** | 小写下划线 | `user_id`, `is_active` | `userId`, `bActive` |
| **成员变量** | 私有/保护单下划线 `_` 后缀 | `name_`, `retry_count_` | `_name`, `m_name` |
| **成员函数** | 小写下划线（私有建议 `_` 结尾） | `calc_total()`, `init_internal_()` | `__init()`（保留字UB） |
| **常量 / 全局** | 常量全大写；全局加 `global_` 前缀 | `MAX_BUFFER_SIZE`, `global_config` | `kMaxBuffer` |
| **命名空间** | 小写下划线 | `namespace core::net` | `namespace CoreNet` |

## 3. 注释规范 (B-CMT)
- 函数与类必须使用**多行分标签 Doxygen 块**：`/**` 与 `*/` 各自独占一行，中间每行以 ` * ` 起首对齐。
- 标签顺序固定：`@brief`（必填）→ `@tparam` → `@param` → `@return` → `@throws` / `@note`；有参数或返回值时必须逐项成行。
- **严禁单行压缩写法**（如 `/** @brief ... */`）；**函数体内严禁业务解释性行内注释**（仅放行 `// NOLINT`、`/* fallthrough */` 等编译指令）。

```cpp
// ✅ 正例：多行分标签 Doxygen 文档头，函数体内零业务注释
/**
 * @brief 订阅键变更（响应式热调，零轮询）
 * @tparam T 支持类型
 * @param name 配置键
 * @param on_changed 变更回调（收到新值）
 * @return  RAII 订阅守卫，业务方必须持有；析构守卫即退订
 */
template <typename T>
subscription_guard_t subscribe(std::string_view name, std::function<void(const T&)> on_changed) {
    return registry_.add_listener<T>(name, std::move(on_changed));
}

// ❌ 反例 1：单行压缩文档头（违反 B-CMT）
/** @brief 计算用户综合评分：基础分 + 活跃度加成。 */

// ❌ 反例 2：函数体内业务注释（违反 B-CMT）
int calc_score(const user_t& user) {
    int bonus = user.active_days * BONUS_PER_DAY; // 活跃加成（错！）
    return user.base_score + bonus;               // 返回总分（错！）
}
```
