## 1. 现代特性核心规范

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-INIT]**  | MUST | 优先统一 `{}` 初始化防窄化；空指针必须使用 `nullptr` | 使用 `NULL` 或字面量 `0`；`auto* p = new` 裸 new |
| **[R-CPP-BIND]**  | MUST | 多返回值使用结构化绑定（`const auto& [a, b]`）；编译期分支用 `if constexpr` | 运行时低效条件分发；复杂 SFINAE 嵌套 |
| **[R-CPP-ATTR]**  | MUST | 有返回值且忽略属隐患的函数标 `[[nodiscard]]`；未用参数显式标 `[[maybe_unused]]` | 忽略关键返回值；使用 `(void)param;` 强转抑制警告 |
| **[R-CPP-CPT]**   | MUST | 泛型类型约束优先使用 C++20 `concept` | 滥用 `std::enable_if_t` 冗长实现 |

```cpp
// ✅ C++20 Concept 约束
template<std::integral T>
[[nodiscard]] T add(T a, T b) noexcept { return a + b; }
```

## 2. 模板与泛型编程

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-CPP-TMPL-ALIAS]**| MUST | 类模板必须通过 `using` 提供语义别名（`value_type`, `size_type`） | 接口直接暴露裸类型形参 `T` |
| **[R-CPP-TMPL-PLACE]**| MUST | 模板声明与实现**统一定义在同一 `.h` 头文件内**（无需 `.inl`） | 非显式实例化模板拆入 `.cpp` 导致链接失败 |
| **[R-CPP-TMPL-INLN]** | MUST | 复杂成员函数必须放在**类声明外部**定义；仅 1~3 行极短 Getter 允许类体内内联 | 巨型实现直接写在类体内导致隐式内联与代码膨胀 |

```cpp
// ✅ 正例：类模板规范布局（短方法类内，复杂实现类外，统一在 .h）
template<typename T>
class buffer_queue_t {
public:
    using value_type = T;
    [[nodiscard]] std::size_t size() const noexcept { return size_; } // 极短内联
    void push(const value_type& val);                                 // 复杂实现仅声明
private:
    std::vector<value_type> data_;
    std::size_t size_{0};
};

template<typename T>
void buffer_queue_t<T>::push(const value_type& val) {
    if (data_.capacity() == size_) { data_.reserve(size_ == 0 ? 8 : size_ * 2); }
    data_.push_back(val);
    ++size_;
}
```
