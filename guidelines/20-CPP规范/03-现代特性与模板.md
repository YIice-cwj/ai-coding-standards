## 7. 现代 C++ 核心特性

### 7.1 初始化规则
- **优先**使用大括号列表初始化 `{}` 防止隐式窄化转换。
- **例外**：当 `{}` 会被优先解析为 `std::initializer_list` 从而改变语义时（如 `std::vector<int> v(10, 0)` 创建 10 个 0），**必须**使用圆括号 `()`。
- **必须**使用 `nullptr`，**严禁**使用 `NULL` 或裸字面量 `0` 表示空指针。

### 7.2 auto 类型推导
- `auto` **必须**在声明时立即初始化，**禁止**用于无明显初始类型推导的场景。
- **禁止的 auto 反模式**：
  ```cpp
  auto x = {1, 2, 3};      // 错！推导为 std::initializer_list<int> 而非 vector
  auto* p = new widget_t;   // 错！严禁裸 new
  ```

### 7.3 结构化绑定与编译期分支
- 多返回值与键值对解构**必须**使用结构化绑定（C++17）：`const auto& [id, name] = *record_iter;`。
- 编译期分支**必须**使用 `if constexpr` 代替 SFINAE。

### 7.4 C++20 Concept 与模板约束
- 模板参数约束**必须优先使用 C++20 `concept`**，替代过时的 `std::enable_if_t` / SFINAE：

**正例**：
```cpp
template<std::integral T>
T add(T a, T b) noexcept {
    return a + b;
}
```

**反例**：
```cpp
template<typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
T add(T a, T b) { return a + b; }  // 错！过时的 SFINAE
```

### 7.5 标准属性 (Attributes)
- 有返回值且忽略返回值属于严重逻辑漏洞的函数，**必须**标记 `[[nodiscard]]`：
  ```cpp
  [[nodiscard]] bool connect();
  [[nodiscard]] std::unique_ptr<session_t> create_session();
  ```
- 接口预留或回调中暂未使用的形参，**必须**显式标记 `[[maybe_unused]]`，**禁止**使用 `(void)param;` 强转：
  ```cpp
  void on_notify([[maybe_unused]] const event_t& evt) noexcept {}
  ```

## 9. 模板与泛型编程

### 9.1 类模板语义化别名
- 类模板**必须**通过 `using` 为模板参数及派生类型定义标准的语义别名（如 `value_type`, `size_type`, `reference` 等），放置在 public 类型定义区。
- 类模板内部（含成员函数参数与返回值）**禁止直接出现裸类型形参 `T`**，必须使用别名：

**正例**：
```cpp
template<typename T>
class buffer_queue_t {
public:
    using value_type = T;
    using size_type  = std::size_t;

    [[nodiscard]] size_type size() const noexcept;
    void push(const value_type& val);
};
```

### 9.2 模板定义放置与内联控制
- **无需分离文件**：类模板与函数模板**无需**通过独立文件（如 `.inl`）分离实现，所有声明与实现**全部统一定义在 `.h` 头文件中**。
- **复杂函数类外定义**：复杂成员函数（非平凡逻辑、多行实现）**严禁**直接定义在类声明体内，**必须**放置在类体外部（在同一 `.h` 文件的类声明之后）进行定义，确保类接口清晰紧凑。
- **严禁复杂函数内联**：**严禁**出现复杂函数的内联（包括因直接在类体内定义导致的隐式内联，或显式标注 `inline` 导致内联膨胀）；仅极短实现（1~3 行的简单 getter/转发或概念受约束函数）**允许**在类体内直接内联。
- **禁止普通实现入 .cpp**：**禁止**将普通模板实现单独写入 `.cpp`（显式实例化或全特化特例除外）。

**正例**：
```cpp
// 统一定义在同一 .h 头文件中，无需 .inl 等分离文件
template<typename T>
class buffer_queue_t {
public:
    using value_type = T;
    using size_type  = std::size_t;

    // 极短实现允许在类体内内联
    [[nodiscard]] size_type size() const noexcept {
        return size_;
    }

    // 复杂成员函数仅在类内声明，严禁在类内直接实现
    void push(const value_type& val);

private:
    std::vector<value_type> data_;
    size_type size_{0};
};

// 复杂函数必须在类体外定义，严禁内联
template<typename T>
void buffer_queue_t<T>::push(const value_type& val) {
    if (data_.capacity() == size_) {
        data_.reserve(size_ == 0 ? 8 : size_ * 2);
    }
    data_.push_back(val);
    ++size_;
}
```

**反例**：
```cpp
template<typename T>
class buffer_queue_t {
public:
    using value_type = T;

    // 错！复杂函数直接在类体内定义，导致隐式内联膨胀且破坏类结构简洁性
    void push(const value_type& val) {
        if (data_.capacity() == size_) {
            data_.reserve(size_ == 0 ? 8 : size_ * 2);
        }
        data_.push_back(val);
        ++size_;
    }
};
```
