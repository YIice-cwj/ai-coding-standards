## 7. 现代 C++ 核心特性

### 7.1 初始化与类型推导
- **初始化**：优先使用 `{}` 防止窄化；需指定元素数量时用 `()`（如 `std::vector<int> v(10, 0)`）；必须用 `nullptr`，严禁 `NULL` 或 `0`。
- **auto 规范**：声明时必须初始化；禁止推导歧义（如 `auto x = {1, 2}` 误推为 `initializer_list`，严禁 `auto* p = new ...` 裸 new）。
- **结构化绑定与 constexpr**：多返回值使用 `const auto& [a, b] = tuple;`；编译期分支必须使用 `if constexpr` 替代 SFINAE。

### 7.2 C++20 Concept 与标准属性
- **Concept 约束**：模板约束优先使用 `concept`，替代过时的 SFINAE：
  ```cpp
  // ✅ C++20 Concept
  template<std::integral T>
  T add(T a, T b) noexcept { return a + b; }

  // ❌ 过时的 std::enable_if_t
  template<typename T, typename = std::enable_if_t<std::is_integral_v<T>>>
  T add(T a, T b) { return a + b; }
  ```
- **标准属性**：有返回值且忽略属逻辑漏洞的函数标记 `[[nodiscard]]`；未使用的回调形参显式标注 `[[maybe_unused]]`（严禁 `(void)param;` 强转）。

## 9. 模板与泛型编程

### 9.1 类模板语义化别名
- 类模板必须通过 `using` 为模板形参定义语义别名（`value_type`, `size_type`），接口处禁止直接暴露裸类型形参 `T`：
  ```cpp
  template<typename T>
  class buffer_queue_t {
  public:
      using value_type = T;
      using size_type  = std::size_t;

      [[nodiscard]] size_type size() const noexcept;
      void push(const value_type& val);
  };
  ```

### 9.2 模板定义放置与内联控制
- **无需 `.inl` 分离文件**：模板声明与实现**统一定义在 `.h` 头文件中**。
- **复杂函数类外定义**：复杂成员函数**严禁在类声明体内直接实现**，必须放在类体外部（同在 `.h` 中），防止隐式内联膨胀；仅极短实现（1~3 行 Getter/转发）允许类体内内联。
- **禁止普通实现入 `.cpp`**：非显式实例化模板禁止写入 `.cpp`。

```cpp
// ✅ 正例：统一定义在同一 .h 头文件中
template<typename T>
class buffer_queue_t {
public:
    using value_type = T;
    [[nodiscard]] std::size_t size() const noexcept { return size_; } // 极短内联
    void push(const value_type& val); // 复杂函数仅声明
private:
    std::vector<value_type> data_;
    std::size_t size_{0};
};

// 复杂实现定义在类外，严禁内联
template<typename T>
void buffer_queue_t<T>::push(const value_type& val) {
    if (data_.capacity() == size_) { data_.reserve(size_ == 0 ? 8 : size_ * 2); }
    data_.push_back(val);
    ++size_;
}
```
