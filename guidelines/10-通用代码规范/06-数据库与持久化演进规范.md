## 1. 核心持久化红线对照表

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-DB-DDL]**   | MUST | 大表结构变更必须采用**展开-收缩六步法**（新增可空列 $\to$ 双写 $\to$ 异步回刷 $\to$ 读切新列 $\to$ 设非空 $\to$ 删旧列） | 大表直接 `ADD COLUMN NOT NULL`（排他锁表）；直接重命名正使用列 |
| **[R-DB-TX]**    | MUST | 事务范围最小化：仅包裹纯粹原子持久化；毫秒级释放 | 事务中夹带远程 RPC、第三方 HTTP、发信或高耗时 CPU 运算（导致连接池雪崩） |
| **[R-DB-N1]**    | MUST | 关系数据批量加载：收集所有键后单次批量 `IN (...)` 或 `JOIN` 查询，在内存中哈希组装 | 在 `for` 循环体内针对每一项执行单条独立 SQL 查询（N+1 查询灾难） |
| **[R-DB-PROJ]**  | MUST | 显式指定具体投影列字段（`SELECT id, name`） | 无脑 `SELECT *` 拉取不必要的宽表长字段（`TEXT`/`BLOB`）耗尽带宽与内存 |
| **[R-DB-PARAM]** | MUST | 强制使用参数化预编译绑定（Prepared Statements） | 使用 `+` 或格式化字符串直接拼接 SQL 语句（一票否决 SQL 注入隐患） |

## 2. 模式对比与正反例 (❌ vs ✅)

### 2.1 局部窄事务 (Narrowest Scope) [R-DB-TX]
```cpp
// ❌ 反例：事务内夹带外部 HTTP 调用（网络波动直接堵死数据库连接池）
void checkout(db_session_t& session, const request_t& req) {
    auto tx = session.begin_transaction();
    const auto pay_res = http_client.post("https://pay.gateway/charge", req.info);
    session.execute("UPDATE orders SET status = 'PAID' WHERE id = ?", req.order_id);
    tx.commit();
}

// ✅ 正例：外部 I/O 置于事务外，仅在写入阶段开启毫秒级短事务
void checkout(db_session_t& session, const request_t& req) {
    const auto pay_res = http_client.post("https://pay.gateway/charge", req.info);
    if (!pay_res.is_success()) return;

    auto tx = session.begin_transaction();
    session.execute("UPDATE orders SET status = 'PAID' WHERE id = ?", req.order_id);
    tx.commit();
}
```

### 2.2 防 N+1 循环查库 [R-DB-N1]
```cpp
// ❌ 反例：循环内单条查库（典型 N+1 性能崩溃）
for (const auto& order : orders) {
    auto items = session.query("SELECT name FROM items WHERE order_id = ?", order.id);
}

// ✅ 正例：提取所有 ID 一次性批量加载并在内存中哈希装配
const auto order_ids = extract_ids(orders);
const auto all_items = session.query_batch("SELECT order_id, name FROM items WHERE order_id IN (?)", order_ids);
const auto item_map = group_by_order_id(all_items);
```

## 3. 自检清单 (Checklist)
- [ ] DDL 变更无排他性锁表语句，字段变更已规划平滑过渡。
- [ ] 数据库事务内部零外部网络请求与长耗时计算。
- [ ] 循环体内零独立 SQL 查询，数据通过批量查询加载。
- [ ] 所有动态参数均经过预编译参数化绑定，无 SQL 拼接。
