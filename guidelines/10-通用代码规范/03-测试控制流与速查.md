## 7. 测试规范与真测试契约 (Anti-Hollow Testing Protocol)

- **三路覆盖与禁 sleep 盲等**：核心逻辑覆盖正常流、边界极值与异常流；测试异步逻辑**严禁硬编码 `sleep()` 盲等**，必须使用事件回调、超时轮询或虚拟时钟。
- **严禁同义反复式 Mock (No Tautological Mocks)**：业务计算规则、状态机流转与数据校验**必须在真实内存对象中运行**；Mock 仅允许用于外部不可控边界（网络 RPC、第三方 HTTP、发信服务、物理时钟）。
- **断言深度要求 (No Hollow Assertions)**：严禁仅断言 `assertNotNull` 或永真表达式；必须精确断言业务返回值、状态转移字段、副作用及抛出的具体异常类型与错误码。
- **严禁为单测破坏封装**：严禁仅为单测访问将 `private` 改为 `public`；通过 Public 契约与可见副作用测试，或使用测试友元受控暴露。

## 8. 控制流与代码简洁原则

### 8.1 提前返回 (Guard Clause)
主逻辑保持线性一路向下，杜绝深层嵌套：

```python
# ✅ 正例：Guard Clause 扁平化
def process_order(order: Order) -> bool:
    if not order.is_valid or order.is_cancelled:
        return False
    return execute_payment(order)

# ❌ 反例：嵌套右移
def process_order(order: Order) -> bool:
    if order.is_valid:
        if not order.is_cancelled:
            return execute_payment(order)
    return False
```

### 8.2 必要防御原则与杜绝过度防御（Python 对照）
> **准则 SSOT**：[行为规范 · Stage 3](../00-行为规范/01-核心铁律与五阶执行模型.md#stage-3-极简实现与最小变更)（非必死不判断，信契约弃臆想）。

```python
# ✅ 正例：像人类工程师一样聚焦关键业务边界
def process_user_payment(order: Order, wallet: Wallet) -> bool:
    """处理用户支付扣款。仅校验余额不足这一真实业务边界。"""
    if wallet.balance < order.total_amount:
        return False
    wallet.deduct(order.total_amount)
    return True

# ❌ 反例：AI 典型的神经过敏过度防御（内部链路层层设卡）
def process_user_payment(order: Order, wallet: Wallet) -> bool:
    if order is None or wallet is None: return False      # 错！类型系统与上游已保证
    if order.total_amount is None or order.total_amount < 0: return False  # 错！领域模型已保证合法
    if wallet.user_id != order.user_id: return False     # 错！鉴权中间件已保证，属臆想设卡
    if wallet.balance < order.total_amount:
        return False
    wallet.deduct(order.total_amount)
    return True
```

### 8.3 安全等价合并与死代码消除
在触及代码范围内，确证 100% 行为等价与零破坏性的未引用变量、死代码或高可读合并，**允许直接修改优化，无需征求同意**；严禁未经证实的盲目简化破坏业务契约。

## 附录：高频自检对照表

| 检查维度 | 合规要求 | 常见反模式拦截 |
|---|---|---|
| **注释整洁** | 函数内零业务注释；思路集中在头部文档注释 | 函数体内写业务解释；注释写独白或残留死代码 |
| **类型标注** | TS/Python/Go 强类型；TS 禁滥用 `any` | 复杂对象直接标 `any`；Python 忽略类型标注 |
| **错误处理** | 精确捕获具体异常；资源 100% 释放 (RAII/defer) | 空 `catch {}` 吞异常；捕获过宽 `Exception` |
| **异步并发** | 显式 `await` 或链式处理；共享数据加锁同步 | 出现 Floating Promise；无同步并发读写 |
| **真实测试** | 真实内存对象测核心逻辑；断言具体业务值与异常 | 全量 Mock 变成同义反复；测试用 sleep 盲等；空洞断言判非空 |
| **控制流** | Guard Clause 提前返回；内部链路信任契约 | 多层嵌套 `if-else`；为 0.1% 极小概率设卡 |
