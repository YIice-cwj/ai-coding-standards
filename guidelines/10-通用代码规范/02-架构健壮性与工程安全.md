## 3. 架构设计与工程七大守则

所有工程设计与功能实现**必须**遵循以下核心原则：
1. **单一职责 (SRP)**：模块或函数只做一件事，禁止几百行的巨型函数。
2. **开闭原则 (OCP)**：对扩展开放，对修改关闭；通过扩展而非修改核心代码实现新需求。
3. **里氏替换 (LSP)**：子类或派生实现必须能完全替换基类或接口，保持行为一致。
4. **依赖倒置 (DIP)**：高层业务逻辑依赖抽象接口，而非直接依赖具体底层实现。
5. **接口隔离 (ISP)**：保持接口精简聚焦，禁止强迫调用方依赖不需要的方法。
6. **DRY 原则 (Don't Repeat Yourself)**：严禁复制粘贴逻辑，公共代码收敛复用。
7. **KISS 原则 (Keep It Simple, Stupid)**：保持代码简单直接，禁止过度设计与预留抽象。

### 3.1 平滑演进规范 (Expand-Contract / 展开-收缩模式)

跨模块重构、公共 API 升级或存储协议迁移时，**严禁大爆炸式一次性重写 (Big-Bang Rewrite)**：

```
[v1 稳定] ──► Step 1: 展开 (新增 v2 契约，v1 保持可用并通过适配器桥接至 v2，随时可编译运行)
          ──► Step 2: 迁移 (调用方逐个迁移至 v2，每迁一个执行客观回归验证)
          ──► Step 3: 收缩 (v1 标记 @deprecated；全量切换后安全移除旧实现与桥接代码)
```

- **步步可编译**：重构拆分为独立原子步骤，严禁使工程处于连续多个阶段不可编译的状态。
- **保护性测试先行**：改动旧逻辑前先编写黑盒保护测试，锁定已知行为，确保演进零静默退化。

## 4. 健壮性与错误处理

### 4.1 强类型标注
- 支持类型的语言（TypeScript, Python, Go, Java, Rust）必须为公共形参、返回值与结构体标注类型。
- TS 严禁滥用 `any`（使用 `unknown` + 类型收缩，或声明 `interface`）；Python 3 必须标注 `typing`。

### 4.2 精确异常与资源安全
- **严禁裸捕获吞异常**（如空 `catch {}` 或 `except:`）。
- **禁止过宽基类异常**（如 `catch (Exception e)`），必须精确捕获预期类型；仅在网关外层统一优雅降级。
- 外部资源（文件、Socket、DB 连接、锁）确保 100% 释放，优先使用 RAII、`try-with-resources`、`defer`、`using` 或 `with`。

### 4.3 异步与并发安全
- **严禁 Floating Promise / 悬空协程**：所有异步调用必须有明确 `await`、`.catch()` 或结构化取消机制。
- 共享可变数据必须使用并发安全同步原语（互斥锁、Channel、原子操作），严禁竞态读写。

**TypeScript 对照**：
```typescript
// ✅ 正确：显式 await 并精确处理具体错误
try {
    await fetch_user_data(user_id);
} catch (error: unknown) {
    if (error instanceof NetworkTimeoutError) { return fallback_user_data; }
    throw error;
}

// ❌ 错误：悬空 Promise 且吞异常
try {
    fetch_user_data(user_id); // 漏 await
} catch (e) {}
```

## 5. 工程化、依赖与供应链安全

- **Lint 与格式化**：配置静态检查工具（ESLint, Ruff, golangci-lint 等），提交前必须校验通过。
- **依赖锁版本**：严禁擅自引入未报备依赖，优先使用标准库；必须提交并维护 lockfile（`package-lock.json`, `Cargo.lock`, `poetry.lock` 等），禁止 `latest` 或 `*` 通配符；严格防范 GPL 等强传染性开源协议。

---

## 6. 可观测性与安全规范

- **结构化日志**：统一日志框架，按级别划分（`DEBUG`, `INFO`, `WARN`, `ERROR`）；核心链路包含 Trace ID。
- **机密防护**：严禁在代码、日志、配置文件、单测中硬编码密钥、密码与 Token。
- **注入防御**：数据库操作必须使用参数化查询（Prepared Statements）或 ORM 绑定，**严禁拼接 SQL 字符串**；表名/列名必须使用白名单校验。
- **12-Factor 配置**：配置从环境变量或配置中心读取；`.env` 必须加入 `.gitignore`（仅提供 `.env.example` 模板）；应用启动时对必填配置做强校验并快速失败。
