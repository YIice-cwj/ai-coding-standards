## 2. 服务边界与配置

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-PY-ASGI]** | MUST | 连接池、HTTP 客户端等长生命周期资源在应用 Lifespan 中创建与释放；请求级资源通过依赖注入 | 在请求处理函数内重复创建连接池；模块级全局可变客户端 |
| **[R-PY-TIMEOUT]** | MUST | 入站请求与出站调用均设置超时；超时返回明确错误并释放资源 | 无超时等待；超时后继续使用已失效连接 |
| **[R-PY-ERROR]** | MUST | 异常映射为统一错误信封（`error_code`/`message`/`trace_id`）；内部堆栈不返回客户端 | 直接把数据库/内部堆栈暴露给调用方；错误响应无 `trace_id` |

```python
@asynccontextmanager
async def lifespan(app: Application) -> AsyncIterator[None]:
    app.state.db = create_engine(settings.database_url)
    app.state.http = httpx.AsyncClient(timeout=5.0)
    yield
    await app.state.http.aclose()
    app.state.db.dispose()
```

## 3. 数据访问、事务与迁移

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-PY-DB-SESSION]** | MUST | Session 按请求或工作单元创建；使用上下文管理器关闭/回滚；禁止跨线程共享 | 模块级全局 Session；请求结束后 Session 未关闭；多线程共享同一 Session |
| **[R-PY-DB-TX]** | MUST | 事务仅包裹原子持久化；外部 HTTP/RPC 放在事务外；短事务、快释放 | 事务内调用第三方 API；长事务持有连接池；失败不回滚 |
| **[R-PY-DB-N1]** | MUST | 关系数据使用批量查询或 `selectinload`/`joinedload`；热路径检查执行计划 | 循环内单条查询（N+1）；Session 外触发懒加载；无索引的全表扫描 |
| **[R-PY-MIGRATION]** | MUST | Schema 变更使用 Alembic 迁移；迁移脚本经审查并在测试库验证；提供回滚预案 | 生产手工执行 DDL；不可逆迁移无备份；迁移与代码发布无顺序约束 |

```python
with session_factory() as session:
    stmt = (
        select(Order)
        .where(Order.user_id == user_id)
        .options(selectinload(Order.items))
    )
    orders = session.scalars(stmt).all()
    session.commit()
```

## 4. 日志、安全与测试

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-PY-LOG]** | MUST | 结构化日志绑定 `trace_id`；字段脱敏；生产关闭 DEBUG | 裸 `print` 业务日志；明文 PII/Token；高频循环刷日志 |
| **[R-PY-SEC]** | MUST | 外部输入边界校验；禁止 `eval`/`exec`/`pickle` 处理不可信数据；密码强哈希；依赖漏洞扫描 | SQL 拼接；硬编码密钥；反序列化外部对象 |
| **[R-PY-DB-TEST]** | MUST | Repository/迁移测试使用真实数据库或容器；事务回滚隔离；覆盖失败与并发边界 | 全量 Mock 数据层；测试共享脏数据；只测正向路径 |

## 5. 自检清单

- [ ] 使用 `src/` 布局，测试目录镜像源码，包边界与导入方向清晰。
- [ ] `pyproject.toml` 为依赖与工具配置单一来源，Lockfile 已提交。
- [ ] 长生命周期资源在 Lifespan 创建/释放，请求级资源依赖注入。
- [ ] 入站与出站调用均有超时，错误统一信封且不泄露内部堆栈。
- [ ] Session 按请求/工作单元隔离，事务短小且失败回滚。
- [ ] 热路径无 N+1，关系数据批量加载或显式 eager load。
- [ ] Schema 变更通过 Alembic，迁移已在测试库验证并有回滚预案。
- [ ] 日志结构化、绑定 `trace_id` 且脱敏，无 PII/Token 泄露。
- [ ] 外部输入经校验，不可信数据不进入 `eval`/`exec`/`pickle`。
- [ ] 数据层与迁移测试使用真实数据库，测试隔离且覆盖异常路径。
