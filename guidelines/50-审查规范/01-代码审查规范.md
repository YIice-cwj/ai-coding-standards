## 一、 审查维度与一票否决项 (Veto Criteria)

审查代码变更（Git Diff）时，若触犯以下任意一项，**直接判定为 BLOCKER 并一票否决打回**：

| 审查维度 | 违规判定标准 (BLOCKER 打回) | 允许放行特权与豁免标准 |
|---|---|---|
| **1. 过度防御 (B4)** | 内部受信任链路层层设卡；为 0.1% 极小概率虚构防御；判断引用非空（`&ref == nullptr`）或判断 `this == nullptr` | 仅外部不可信边界（HTTP/RPC/未校验文件/Public SDK API）设防 |
| **2. 注释纯粹性与同步 (B-CMT)**| 函数体内出现业务解释行内/块注释；**文档头写成单行压缩 `/** @brief ... */` 或缺失 `@param/@return` 标签**；注释含独白或残留死代码；**修改或修复代码后未同步刷新函数文档头注释，或注释与真实实现存在脱节不一致（过时/虚假注释）** | 仅放行静态分析指令（`// NOLINT`、`# type: ignore`）；文档头为多行分标签块且与实现 100% 对齐 |
| **3. 变更边界 (B3)** | 顺手修改无关代码；大面积擅自重排版或重命名未触及符号 | 触及范围内确证 100% 无副作用的未引用变量删除、死代码清理与等价合并 |
| **4. 语言专有陷阱** | **C++**: `return std::move(p)` 阻断 NRVO；返回临时对象 view；漏标 `override`/`noexcept`；非 15 层排布<br>**UE5**: 漏标 UPROPERTY 遭 GC 误杀；非大驼峰或带 `_t`；非 GameThread 摸 UObject | 严格遵循 C++ 与 UE5 专有规范约束 |
| **5. 缺陷根治 (B7)** | 报错点就地判空/吞异常掩盖根因；修 Bug 漏测上下游契约与全景同类排查 (Pattern Sweep) | 锁定破坏不变式的源头；完成三向测距并排查镜像实现 |
| **6. 真实测试 (B5)** | 核心业务全 Mock 变同义反复；断言仅判非空（`assertNotNull`）；测试使用 sleep 盲等；破坏私有封装 | 真实内存对象测业务逻辑；精确断言具体业务值与异常类型 |
| **7. 工具安全 (B-SEC)** | 代码/日志明文泄露 Key/Token；私装未授权依赖；遗留排查调试临时脚本 | 凭据绝对脱敏掩码；依赖锁版本；工作区绝对洁净 |
| **8. 认知负荷控制** | 复合长表达式未提取意图变量；嵌套三元；缩进深度 > 3 层；裸布尔 Flag 参数控制耦合；散落未命名魔数；反向否定布尔命名 | 落实具名意图常量、正向布尔命名、SLAP 单一抽象层次与具名枚举 |
| **9. 契约/持久化/隐私** | 核心写接口无幂等键防重；无上限全量查询；事务内夹带网络 RPC/HTTP；循环单条查库 (N+1)；日志打印明文 PII | 强制接入幂等协议、游标分页、局部窄事务与 PII 掩码脱敏包装 |
| **10. 职责边界与文件组织 (R-ARCH-CLASS)** | 一个文件堆叠多个业务类；嵌套无关业务类或借嵌套规避单文件单类；UI 类直接修改业务数据或持久化；上帝类跨层越权 | 单文件单类（纯类型聚合头文件除外）；嵌套类为内部实现细节；UI 仅展示与派发意图，数据变更经服务/命令层 |

## 二、 标准审查报告输出模板

AI 审查员在输出审查意见时，**必须严格遵循以下结构化格式**：

```markdown
## 📋 代码审查报告 (Code Review Summary)

### 1. 评审判定
- **结论**: [ PASS (通过) | NEEDS_WORK (需整改) | REJECT (严重否决) ]
- **核心评价**: 一两句话概括本次提交的代码质量与关键问题。

### 2. 缺陷清单 (Issues Found)

#### [BLOCKER] 严重阻断项（必须修正后方可合并）
- **文件与位置**: `src/foo.cc:42`
- **违规规则**: B4 必要防御原则（过度防御性编程）
- **问题说明**: 形参为引用传递，内部却写了 `if (&user == nullptr) return false;`。
- **修改建议**:
  ```diff
  - if (&user == nullptr) { return false; }
  ```

#### [WARNING] 警告项（建议优化）
- **文件与位置**: `src/bar.h:15`
- **违规规则**: 标准属性规范
- **说明与建议**: 创建函数建议添加 `[[nodiscard]]` 标记。
```
