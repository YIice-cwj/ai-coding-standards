## 1. 函数规范与必要防御原则

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-PTR]**    | MUST | 引擎指针统一使用 `TObjectPtr<T>`（UE5.1+）替代裸 `T*` | 声明裸 `UObject*` 成员变量 |
| **[R-UE-DEF]**    | MUST | 信任引擎生命周期保证（`BeginPlay`、`Tick` 中 `GetOwner()`、已注册 Subsystem） | 每个子方法内部重复调用 `IsValid()` / `!= nullptr` 层层设卡 (B4) |
| **[R-UE-UF蔔NC]** | MUST | `BlueprintPure` **必须标记 `const`**；`BlueprintCallable` 必加 `Category` | 状态修改函数标 Pure；漏设 Category 分类 |
| **[R-UE-NATIVE]** | MUST | `BlueprintNativeEvent` 的 C++ 默认实现必须以 `_Implementation` 结尾 | C++ 端漏写 `_Implementation` 后缀 |
| **[R-UE-NOTMPL]** | MUST | UCLASS / USTRUCT / UENUM **严禁作为模板**（UHT 不支持模板反射） | 试图用宏修饰泛型模板类 |

## 2. 严禁 std 库与 UE5 原生映射表

| C++ std 类型 | UE5 强制替代物 | 说明 |
|---|---|---|
| `std::string` / `string_view` | `FString` / `FStringView` / `FText` / `FName` | UI 显示强制用 `FText`；键值用 `FName` |
| `std::vector` / `std::deque` | `TArray` / `TDeque` | 默认首选连续内存 `TArray`（严禁 `std::list`） |
| `std::map` / `std::set` | `TMap` / `TSet` | 默认哈希，支持增量序列化 |
| `std::unique_ptr` / `shared_ptr` | `TUniquePtr` / `TSharedPtr` | 仅限非 UObject 类型；UObject 由 GC 托管 |
| `std::thread` / `std::mutex` | `FAsyncTask` / `TFuture` / `FCriticalSection` | 必须接入引擎 TaskGraph 调度 |
| `std::optional` | `TOptional` | 可选返回值标准封装 |

## 3. 参数传递与 Rule of 0
- **UObject 参数**：使用 `TObjectPtr<T>` 或 `T*` 传递；GC 自动跟踪，无需 `std::move`。
- **复合值类型**：大型对象传 `const TArray<T>&`, `const FString&`；小型内置类型传值。
- **UCLASS 对象**：遵循 **Rule of 0**（由引擎管理合成，禁止自定义深拷贝）。
