## 7. 函数规范与设计

### 7.1 核心约束
- **基础约束**：单参构造函数 `explicit`；所有不抛异常函数标 `noexcept`；必须使用 `nullptr`；**必须使用 `TObjectPtr<T>` 替代裸 `T*`**（UE5.1+）；必须使用 `using`；成员变量声明处初始化；UObject 遵循 Rule of 0。
- **函数设计**：行数建议 $\le 50$；形参建议 $\le 4$；提前返回（Guard Clause）拉平嵌套；禁止非 const 引用出参，使用返回值或 `TOptional`。
- **必要防御原则（信任 UE5 架构契约）**：
  > **准则 SSOT**：[行为规范 · Stage 3](../00-行为规范/01-核心铁律与五阶执行模型.md#stage-3-极简实现与最小变更)。
  - **信任引擎生命周期保证**：在已确证生命周期的引擎回调（如 `BeginPlay`、`Tick` 中 `GetOwner()`、已注册的 Subsystem 等），**严禁在每个子方法内部重复调用 `IsValid()` / `!= nullptr` 层层设卡**。
  - 仅在真正的外部边界（网络 RPC、未校验的玩家输入、跨模块弱指针 `TWeakObjectPtr`）做必要校验。

### 7.2 UE5 反射函数规范 (UFUNCTION)
- `BlueprintCallable`：必须指定 `Category = "模块|子类"`。
- `BlueprintPure`：**必须同时标记 `const`**。
- `BlueprintNativeEvent`：`.cpp` 中实现必须带 `_Implementation` 后缀。
- `BlueprintImplementableEvent`：纯蓝图实现，C++ 端不得定义实现。

## 8. 移动语义与参数传递

- UCLASS 类通常遵循 **Rule of 0**（由编译器生成，UObject 禁止深拷贝）；移动操作标记 `noexcept`。
- **参数传递准则**：
  - 小型结构/内置类型：按值传递。
  - 大型对象（`TArray`, `FString`）：`const TArray<T>&`, `const FString&`。
  - UObject 对象：`TObjectPtr<UObject>` 或 `UObject*`（禁止按值传递；GC 自动跟踪，无需 `std::move`）。

## 9. 禁止 std 容器与引擎对应物

UE5 项目**严禁使用 std 容器与同步原语**，必须使用 UE5 原生类型：

| std 类型 | UE5 对应物 | 说明 |
|---|---|---|
| `std::string` / `string_view` | `FString` / `FStringView` | 文本操作，UI 必须用 `FText`，哈希用 `FName` |
| `std::vector` / `std::deque` | `TArray` / `TDeque` | 默认首选连续内存 `TArray`（严禁 `std::list`） |
| `std::map` / `std::set` | `TMap` / `TSet` | 默认哈希，支持反射与增量序列化 |
| `std::unique_ptr` / `std::shared_ptr` | `TUniquePtr` / `TSharedPtr` | 仅限非 UObject；UObject 由 `NewObject` + GC 托管 |
| `std::function` | `TFunction` | 内存优化，无额外堆分配开销 |
| `std::thread` / `std::mutex` | `FAsyncTask` / `TFuture` / `FCriticalSection` | 与引擎 TaskGraph 调度集成 |
| `std::optional` | `TOptional` | 可选返回值标准封装 |

## 10. 现代 C++ 特性与模板

- **结构化绑定与 constexpr**：支持解构多返回值；编译期分支使用 `if constexpr`；C++20 Concept 禁止加 `_t` 后缀。
- **属性**：重要返回值标记 `[[nodiscard]]`；未使用的形参标记 `[[maybe_unused]]`（严禁 `(void)` 强转）。
- **模板与反射硬红线**：
  - **UCLASS / USTRUCT / UENUM 严禁作为模板**（UHT 不支持模板反射）；泛型需求使用 UObject 多态包装或数据驱动。
  - 非反射纯 C++ 工具类可使用模板：模板声明与实现**统一定义在 `.h` 头文件**（严禁 `.inl`），复杂函数必须在类外定义。
