## 13. 容器与字符串规范

### 13.1 容器最佳实践
- 已知大小时必须调用 `Reserve()`；插入元素优先使用 `Emplace` / `EmplaceBack` 避免临时对象。
- 默认首选连续内存 `TArray`（严禁使用 `std::list` 或手写链表）。
- 返回局部对象直接按值返回，依赖 NRVO；**严禁返回 `std::move` 局部对象**。

### 13.2 三大字符串使用场景
| 类型 | 特性 | 必须场景 | 严禁场景 |
|---|---|---|---|
| **`FText`** | 支持本地化 | 所有 UI 显示文本、玩家可见内容 | 严禁作为哈希键或底层序列化标识 |
| **`FName`** | 不可变、哈希极速 | 字典 Key、GameplayTag、资源插槽名 | 严禁存储易变长文本 |
| **`FString`** | 可变动态字符串 | 文本动态拼接、算法内操作、日志打印 | 严禁在类成员中使用 `const TCHAR*` |

### 13.3 引用与加载类型
- **强引用**：`TObjectPtr<T> + UPROPERTY`（GC 跟踪生命周期）。
- **弱引用**：`TWeakObjectPtr<T>`（打破回环引用，访问前必须 `IsValid()`）。
- **软引用**：`TSoftObjectPtr<T>` / `TSoftClassPtr<T>`（按需异步加载，防内存暴涨）。

## 16. 并发与多线程规范

### 16.1 同步原语与锁
- 互斥锁必须使用 RAII 管理器 `FScopeLock(&CriticalSection)`，严禁手调加解锁。
- 读多写少必须使用 `FRWLock`（`FReadScopeLock` 读锁 / `FWriteScopeLock` 写锁）。
- 持锁区间严禁执行耗时 I/O 或不可控回调。

### 16.2 任务系统与线程安全
- **禁止使用 `std::thread` / `std::jthread`**，统一使用 UE5 任务系统：异步单次任务用 `FAsyncTask` / `Async(EAsyncExecution::ThreadPool, ...)`；多核循环用 `ParallelFor`。
- **UObject 线程铁律**：**严禁在非游戏线程（Non-Game Thread）直接访问或修改 UObject**；必须通过 `FTaskGraphInterface` 调度回游戏线程执行。

## 19. 安全编码规范

- **C 接口与字符串安全**：严禁 `strcpy`, `sprintf`；格式化统一使用 `FString::Printf` 或 `FCString::Snprintf`，且字面量必须用 `TEXT()` 宏包裹。
- **视图生命周期 (FStringView / TArrayView)**：
  - 视图类型为非所有权引用，**严禁返回指向局部临时对象的 `FStringView` 或 `TArrayView`**。
  - 类成员变量**严禁**使用 `FStringView` 存储字符串（必须使用 `FString`）。
  - 函数参数连续切片必须优先使用 `TArrayView<const T>` 替代 `const T* + int32`。
