## 1. 容器与三大字符串使用规范

| 类型 | 强制使用场景 | 绝对严禁场景 (DON'T / 一票打回) |
|---|---|---|
| **`FText`**   | 所有 UI 展现文本、玩家可见内容（支持本地化） | 严禁作为字典哈希 Key 或底层通信序列化标识 |
| **`FName`**   | 字典 Key、GameplayTag、资源插槽名（哈希极速） | 严禁存储可变动态长文本 |
| **`FString`** | 文本动态拼接、算法内操作、日志打印 | 严禁在类成员中使用裸 `const TCHAR*` |
| **`TArray`**  | 默认首选连续内存容器；已知容量前调用 `Reserve()` | **严禁默认使用 `std::list`** 或手写链表 |

- **对象引用**：按需加载使用 `TSoftObjectPtr<T>` 避免内存暴涨；弱引用打破环引用使用 `TWeakObjectPtr<T>`。
- **视图生命周期**：`FStringView` / `TArrayView` 严禁绑定临时对象；类成员变量严禁使用 `FStringView` 存储数据。

## 2. 并发与多线程安全铁律

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-CONC-UOBJ]**| MUST | **严禁在非游戏线程（Non-Game Thread）访问或修改 UObject**；必须通过 `FTaskGraphInterface` 调度回主线程 | 在异步工作线程直接读写 UObject 导致 GC/物理竞态崩溃 |
| **[R-UE-CONC-LOCK]**| MUST | 互斥锁必须使用 RAII 管理器：`FScopeLock(&Mutex)`；读多写少用 `FRWLock` | 手动调用加解锁；持锁期间执行耗时 I/O |
| **[R-UE-CONC-TASK]**| MUST | 异步计算统一使用 UE5 任务系统（`FAsyncTask` / `Async(...)` / `ParallelFor`） | 裸用 `std::thread` / `std::jthread` 绕过引擎调度器 |
| **[R-UE-SAFE-STR]** | MUST | 格式化统一使用 `FString::Printf` 或 `FCString::Snprintf`，且字符串用 `TEXT()` 包裹 | 使用无安全边界的 `sprintf` / `strcpy` |
