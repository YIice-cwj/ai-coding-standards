## 17. 内存管理与 GC

### 17.1 对象创建与 RAII
- **UObject 派生类**：严禁 `new` / `delete` / `std::make_unique`，必须使用 `NewObject<T>(Outer)` 创建，交由引擎 GC 自动管理。
- **非 UObject 类型**：严禁裸 `new` / `delete`，必须使用 `MakeUnique<T>()` (`TUniquePtr`) 或 `MakeShared<T>()` (`TSharedPtr`)。

### 17.2 UPROPERTY 强引用保留机制（高危陷阱）
- **引擎铁律**：类成员中的 `UObject*` / `TObjectPtr<T>` **必须标记 `UPROPERTY()`**（即使不带任何参数）；否则 GC 无法感知强引用，对象会在下一帧或垃圾回收时被静默回收导致空指针崩溃。

```cpp
UCLASS()
class UFlexiBagComponent : public UActorComponent {
    GENERATED_BODY()

    // ✅ 正确：UPROPERTY 保证 GC 强引用
    UPROPERTY(Transient)
    TObjectPtr<UFlexiItemObjectFactory> CachedFactory;

    // ❌ 错误：无 UPROPERTY，随时会被 GC 意外回收崩溃
    TObjectPtr<UFlexiItemObjectFactory> CachedFactoryNoProp;
};
```

### 17.3 智能指针选择决策
```
需要管理 UObject？
├─ 是 ──► TObjectPtr<T> + UPROPERTY (GC 强引用) / TWeakObjectPtr<T> (弱引用防回环)
└─ 否 ──► 需要共享所有权？
           ├─ 是 ──► TSharedPtr<T> (通过 MakeShared 创建)
           └─ 否 ──► 需要独占堆对象？
                      ├─ 是 ──► TUniquePtr<T> (通过 MakeUnique 创建)
                      └─ 否 ──► 优先栈对象或值语义
```
