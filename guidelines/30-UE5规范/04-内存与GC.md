## 1. 对象生命周期与 GC 强引用铁律

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-GC-NEW]**  | MUST | UObject 必须使用 `NewObject<T>(Outer)` 创建，交由 GC 管理 | 针对 UObject 裸调 `new` / `delete` / `std::make_unique` |
| **[R-UE-GC-PROP]** | MUST | 类成员变量中的 `TObjectPtr<T>` **必须标记 `UPROPERTY()`** | 成员指针未标记 UPROPERTY，导致下一帧被 GC 静默回收崩溃 |
| **[R-UE-GC-WEAK]** | MUST | 观察者或可能回环引用的对象强制使用 `TWeakObjectPtr<T>` | 使用强引用导致对象无法正常垃圾回收与关卡卸载泄露 |

```cpp
UCLASS()
class UFlexiBagComponent : public UActorComponent {
    GENERATED_BODY()

    // ✅ 正确：UPROPERTY 保证 GC 强引用感知
    UPROPERTY(Transient)
    TObjectPtr<UFlexiItemObjectFactory> CachedFactory;

    // ❌ 错误：无 UPROPERTY 标记，GC 会在垃圾回收阶段静默将其释放，导致野指针崩溃
    TObjectPtr<UFlexiItemObjectFactory> UnsafeFactory;
};
```

## 2. 智能指针选择决策速查
```
需要管理 UObject？
├─ 是 ──► TObjectPtr<T> + UPROPERTY (GC 强引用) / TWeakObjectPtr<T> (弱引用防回环)
└─ 否 ──► 需要共享所有权？
           ├─ 是 ──► TSharedPtr<T> (通过 MakeShared 创建)
           └─ 否 ──► 需要独占堆对象？
                      ├─ 是 ──► TUniquePtr<T> (通过 MakeUnique 创建)
                      └─ 否 ──► 优先栈对象或值语义
```
