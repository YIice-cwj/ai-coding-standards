## 附录 A：委托类型选择决策树

```
需要蓝图绑定？
├─ 是 ──► 多订阅广播？
│          ├─ 是 ──► DECLARE_DYNAMIC_MULTICAST_DELEGATE + UPROPERTY(BlueprintAssignable) (UI 事件/广播)
│          └─ 否 ──► DECLARE_DYNAMIC_DELEGATE (单订阅蓝图回调)
└─ 否 ──► 多订阅广播？
           ├─ 是 ──► DECLARE_MULTICAST_DELEGATE (纯 C++ 多播，高性能)
           └─ 否 ──► DECLARE_DELEGATE (纯 C++ 单订阅异步回调)
```
- **参数后缀**：无参数无后缀，`_OneParam` ~ `_NineParams`（超过 9 个必须封装为 USTRUCT）。

## 附录 B：UE5 容器选择决策树

```
需要存储键值对？
├─ 是 ──► 需要按键有序遍历？
│          ├─ 是 ──► TMap<K, V, FDefaultSetAllocator, TSortableKeyFuncs> (O(log n))
│          └─ 否 ──► TMap<K, V> (默认哈希表，平均 O(1)) / TSet<K> (去重集合)
└─ 否 ──► 顺序线性访问？
           ├─ 编译期固定大小？ ──► TFixedArray / std::array (栈分配)
           └─ 动态大小：
                ├─ 首尾两端高效插入/弹出？ ──► TDeque (双端队列)
                └─ 默认通用场景 ──► TArray (连续内存，缓存局部性最佳)
```
> **禁忌**：严禁使用 `std::list`；网络增量数组使用 `FFastArraySerializer`。

## 附录 C：C++ 规范与 UE5 冲突仲裁表

C++ 通用规范与 UE5 引擎发生冲突时，按下表仲裁执行：

| 冲突项 | C++ 规范 (20-CPP) | UE5 约束与规范 (30-UE5) | 仲裁结果 | 理由 |
|---|---|---|---|---|
| **头文件顺序** | 对应实现 $\to$ 标准库 $\to$ 第三方 $\to$ 项目 | `CoreMinimal.h` 必须最前，`.generated.h` 必须最后 | **UE5 优先** | UHT/PCH 强制编译要求 |
| **命名风格** | 全小写下划线 (snake_case) | 全域大驼峰 (PascalCase)，布尔必须 `b` 前缀 | **UE5 优先** | 遵循 Epic Games 官方规范，与蓝图及反射对齐 |
| **类前后缀** | `_t` 后缀 | U/A/F/E/I/S/T 前缀，严禁 `_t` 后缀 | **UE5 优先** | UHT 反射与蓝图 API 强约束 |
| **成员装饰** | 私有/保护加 `_` 后缀 | 严禁下划线前缀/后缀，统一大驼峰 | **UE5 优先** | 反射直接暴露给蓝图 Details 面板 |
| **模板实现** | 统一定义在 `.h`，复杂类外实现 | 统一定义在 `.h`，复杂类外实现 | **完全对齐** | 均已彻底取消 `.inl` 分离文件 |
| **内部注释** | 禁止业务解释性行内注释 | 同 C++ 规范（仅放行编译器元指令） | **遵循 C++** | 无冲突 |
| **类结构排布** | public 接口优先，15 层排布 | 同 C++ 规范，反射宏紧随对应区域 | **遵循 C++** | 接口优先原则一致 |
| **异常处理** | 默认状态码/optional | UE5 默认开启 `-fno-exceptions` | **遵循 C++** | 无冲突，UE5 天然禁用异常 |
| **字符串** | `std::string` / `string_view` | `FString` / `FName` / `FText` / `FStringView` | **UE5 优先** | 本地化与哈希检索生态配套 |
| **连续切片** | `std::span` | `TArrayView` | **UE5 优先** | 与 UE 容器生态配套 |
| **智能指针** | `std::unique_ptr` / `shared_ptr` | `TUniquePtr` / `TSharedPtr`（UObject 由 GC 托管） | **UE5 优先** | UObject 必须交由引擎 GC 强引用 |
| **异步并发** | `std::jthread` / `scoped_lock` | `FAsyncTask` / `TFuture` / `FScopeLock` | **UE5 优先** | 必须由 TaskGraph 调度并防跨线程摸 UObject |
| **日志输出** | 统一结构化日志库 | `UE_LOG` + `TEXT()` | **UE5 优先** | 引擎日志分级过滤与控制台集成 |
| **单例管理** | `call_once` 或局部静态 | `USubsystem`（GameInstance / World） | **UE5 优先** | 遵循引擎生命周期自驱动 |
| **模板反射** | 允许泛型类 | `UCLASS` / `USTRUCT` 严禁使用模板 | **UE5 优先** | UHT 引擎层不支持模板反射 |
