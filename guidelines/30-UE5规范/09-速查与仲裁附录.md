## 附录 C：C++ 规范与 UE5 冲突仲裁表

| 冲突项 | 通用 C++ 规范 (20-CPP) | UE5 专有规范 (30-UE5) | 最终裁决 | 裁决依据 |
|---|---|---|---|---|
| **头文件包含** | 对应实现 $\to$ 标准库 $\to$ 第三方 $\to$ 项目 | `CoreMinimal.h` 最前，`.generated.h` 必须最后 | **UE5 优先** | UHT 与引擎 PCH 编译硬约束 |
| **命名法** | 小写下划线 (snake_case) | 全域大驼峰 (PascalCase)，布尔必须 `b` 前缀 | **UE5 优先** | 官方规范，与蓝图及反射对齐 |
| **类前后缀** | 结构体/类带 `_t` 后缀 | U/A/F/E/I 前缀，**严禁 `_t` 后缀** | **UE5 优先** | UHT 反射强约束 |
| **成员修饰** | 私有变量带 `_` 后缀 | 严禁下划线前缀/后缀，统一大驼峰 | **UE5 优先** | 反射直接映射至 Details 面板 |
| **模板实现** | 统一在 `.h` 头文件，复杂放类外 | 统一在 `.h` 头文件，复杂放类外 | **完全一致** | 均已全面废弃 `.inl` 文件 |
| **内部注释** | 函数体内严禁业务解释注释 (B-CMT) | 同 C++ 规范（仅放行编译器元指令） | **统一遵循** | 无冲突 |
| **类排布** | 接口优先，15 层排布 | 同 C++ 规范，反射宏紧随对应访问区 | **统一遵循** | 保持接口对外优先一致 |
| **文件组织** | 单文件单类，纯类型聚合头例外 | 一个主 `UCLASS` 独占一对 `.h/.cpp`；`UINTERFACE` 的 `U`+`I` 成对、无行为 `USTRUCT`/`UENUM` 可集中或随主类声明 | **统一遵循** | 引擎反射结构除外，均禁止多业务类堆叠 |
| **异常处理** | 默认状态码/optional | UE5 默认开启 `-fno-exceptions` | **统一遵循** | UE5 物理禁用异常体系 |
| **字符串** | `std::string` / `string_view` | `FString` / `FName` / `FText` / `FStringView` | **UE5 优先** | 引擎本地化与哈希生态配套 |
| **连续切片** | `std::span` | `TArrayView` | **UE5 优先** | 与引擎容器深度集成 |
| **智能指针** | `std::unique_ptr` / `shared_ptr` | `TObjectPtr`+`UPROPERTY` / `TSharedPtr` | **UE5 优先** | UObject 必须交由引擎 GC 强引用 |
| **并发任务** | `std::jthread` / `scoped_lock` | `FAsyncTask` / `TFuture` / `FScopeLock` | **UE5 优先** | 严禁非游戏线程访问 UObject |
| **单例设计** | 局部静态 / `call_once` | `USubsystem` | **UE5 优先** | 遵循引擎生命周期自驱动 |
| **模板反射** | 允许泛型类 | `UCLASS` / `USTRUCT` **严禁使用模板** | **UE5 优先** | UHT 引擎层不支持泛型反射 |
