## 1. 代码格式

- **缩进与大括号**：4 空格缩进（严禁 Tab）；大括号与关键字同行（K&R 风格），禁止大括号单独占行。
- **文件编码与换行**：UTF-8 无 BOM 编码，统一使用 LF（`\n`）换行符，严禁 CRLF。
- **头文件引用顺序**（`CoreMinimal.h` 必须第一，`.generated.h` 必须最后）：
  ```cpp
  #pragma once
  #include "CoreMinimal.h"                  // 1. 引擎基础头文件（必须第一）
  #include "GameplayTagContainer.h"        // 2. 引擎其他头文件
  #include "FlexiItemSlot.h"               // 3. 项目内部头文件
  #include "FlexiBagComponent.generated.h" // 4. UHT 反射文件（必须最后）

  class UFlexiItemObject;                  // 前向声明放于 include 之后
  ```

## 2. 命名规范（全面遵循 Epic Games 官方标准）

> **官方契约**：全域大驼峰（PascalCase）；**严禁 `_t` 后缀与下划线命名**；布尔变量强制 `b` 前缀。

### 2.1 类型命名前缀（UHT 强约束）

| 类型 | 前缀 | 规则与示例 |
|---|:---:|---|
| **UObject 派生类** | `U` | `UFlexiBagComponent` |
| **AActor 派生类** | `A` | `AFlexiItemPickupActor` |
| **结构体与纯 C++ 类** | `F` | `FFlexiItemSlot`, `FVector`, `FFlexiBagManager`（严禁 `_t` 后缀） |
| **枚举类** | `E` | `enum class EFlexiSortDirection : uint8 { Ascending, Descending };` |
| **接口类** | `I` + `U` | `IFlexiBagFeatureInterface` / `UFlexiBagFeatureInterface` |
| **Slate 控件** | `S` | `SFlexiBagSlot` |
| **模板参数** | `T` | `TArray<T>`, `typename TContainer` |

### 2.2 变量、形参与成员命名
- **全域 PascalCase**：局部变量（`SlotIndex`）、形参（`const FString& CharacterName`）、成员变量（`SlotArray`）统一使用大驼峰，**严禁下划线前缀或后缀**（避免污染蓝图与 Details 面板）。
- **布尔变量强制 `b` 前缀**：无论成员、局部变量或形参，布尔变量必须遵循 `b` + 大驼峰（`bIsActive`, `bIsInitialized`, `bCanEverTick`），严禁 `is_active` 或 `isActive`。
- **常量与全局**：常量推荐大驼峰（`static constexpr int32 MaxBufferSize = 1024;`）；宏必须全大写加下划线；全局变量/单例指针使用 `G` 前缀（`GEngine`, `GWorld`），优先使用 `USubsystem`。
- **命名空间与函数**：命名空间大驼峰（`namespace UE::FlexiBag`）；函数动词大驼峰（`InitSlots()`，私有函数亦为无装饰大驼峰）；网络 RepNotify 为 `OnRep_属性名`；委托回调以 `On` 开头。

## 3. 注释规范与函数内部零注释

> **准则 SSOT**：函数体内零业务注释、注释纯粹性见 [行为规范 · Stage 3](../00-行为规范/01-核心铁律与五阶执行模型.md#stage-3-极简实现与最小变更)。

- 函数上方使用 `/** */` 文档注释说明功能、参数、返回值与实现思路；类上方注释用于编辑器 Details 面板的 tooltip。
- **函数体内严禁任何业务解释性行内或块注释**（仅放行静态分析指令如 `// NOLINT`）。

**正例**：
```cpp
/**
 * @brief 计算用户得分
 * @param User 用户信息
 * @return 加权后的得分
 *
 * 思路：基础分 + 活跃度加成 - 违规惩罚
 */
int32 CalculateScore(const FUserData& User) const {
    const int32 Base = User.BaseScore;
    const int32 Bonus = User.ActiveDays * BONUS_PER_DAY;
    const int32 Penalty = User.Violations * PENALTY;
    return Base + Bonus - Penalty;
}
```

**反例**：
```cpp
int32 CalculateScore(const FUserData& User) const {
    int32 Base = User.BaseScore;
    int32 Bonus = User.ActiveDays * BONUS_PER_DAY;  // 活跃度加成（错！禁行内注释）
    int32 Penalty = User.Violations * PENALTY;       // 惩罚（错！禁行内注释）
    return Base + Bonus - Penalty;                  // 错！废话注释
}
```
