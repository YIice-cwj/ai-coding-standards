## 1. 格式排版与头文件顺序
- **基础格式**：4 空格缩进（严禁 Tab）；K&R 大括号同行；UTF-8 无 BOM + LF (`\n`)。
- **Include 顺序铁律**（`CoreMinimal.h` 第一，`.generated.h` 必最后）：
  ```cpp
  #pragma once
  #include "CoreMinimal.h"                  // 1. 引擎基础头文件（必须最前）
  #include "GameplayTagContainer.h"        // 2. 引擎其他头文件
  #include "FlexiItemSlot.h"               // 3. 项目内部头文件
  #include "FlexiBagComponent.generated.h" // 4. UHT 反射文件（必须最后）
  class UFlexiItemObject;                  // 前向声明放于 include 之后
  ```

## 2. 命名规则对照表（Epic Games 官方标准）

| 类型分类 | 前缀/规则 | 正确示例 | 严禁反模式 (DON'T / 一票打回) |
|---|:---:|---|---|
| **UObject 派生类** | `U` | `UFlexiBagComponent` | 漏 U 前缀；下划线小写 |
| **AActor 派生类**  | `A` | `AFlexiItemPickupActor` | 漏 A 前缀 |
| **纯 C++ 类/结构体**| `F` | `FFlexiItemSlot`, `FFlexiBagManager` | **严禁 `_t` 后缀**；漏 F 前缀 |
| **枚举类**         | `E` | `enum class EFlexiSortMode : uint8 { Asc, Desc };` | 裸 `enum`；未以 E 开头 |
| **接口类**         | `I` / `U` 成对 | `IFlexiBagInterface` / `UFlexiBagInterface` | 缺失 `U` 接口包装类 |
| **Slate 控件**     | `S` | `SFlexiBagSlot` | 漏 S 前缀 |
| **模板参数**       | `T` | `TArray<T>`, `typename TContainer` | 裸 `Type` |
| **布尔量 (全域)**   | `b` + PascalCase | `bIsActive`, `bCanEverTick` | `isActive`, `is_active`, 漏 `b` |
| **变量/形参/成员**  | PascalCase | `SlotIndex`, `CharacterName` | 下划线命名（`slot_index_` 污染反射面板） |
| **网络 RepNotify** | `OnRep_属性名` | `OnRep_Inventory()` | 乱命名 Rep 回调 |

## 3. 注释规范 (B-CMT)
- 函数与类上方使用 `/** */` 文档注释（用于生成蓝图节点与 Details 面板 Tooltip）。
- **函数体内严禁业务解释性行内注释**（仅放行静态分析指令 `// NOLINT`）。

```cpp
// ❌ 反例：函数内写业务注释（违反 B-CMT）
int32 CalculateScore(const FUserData& User) const {
    const int32 Bonus = User.ActiveDays * BONUS_PER_DAY; // 活跃度加成（错！）
    return User.BaseScore + Bonus;                       // 最终得分（错！）
}

// ✅ 正例：思路集中于函数文档头
/** 计算用户得分：基础分 + 活跃度加成。 */
int32 CalculateScore(const FUserData& User) const {
    const int32 Bonus = User.ActiveDays * BONUS_PER_DAY;
    return User.BaseScore + Bonus;
}
```
