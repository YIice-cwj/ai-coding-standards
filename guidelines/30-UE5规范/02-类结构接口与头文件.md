## 4. 类结构排布（接口优先原则）

UE5 类遵循“公开接口优先 (Interface-First)”排布，`.cpp` 实现顺序必须与头文件类声明 1:1 严格对齐：

```cpp
class UFlexiBagComponent : public UActorComponent {
public:    // 1. public 类型定义 (USTRUCT 嵌套 / using)
protected: // 2. protected 类型定义
private:   // 3. private 类型定义
public:    // 4. public 常量
protected: // 5. protected 常量
private:   // 6. private 常量
public:    // 7. public 成员函数 (构造/析构/业务接口/UFUNCTION - 接口对外优先展现)
protected: // 8. protected 成员函数
private:   // 9. private 成员函数
public:    // 10. public 静态函数
protected: // 11. protected 静态函数
private:   // 12. private 静态函数
private:   // 13. private 成员变量 (含 UPROPERTY) 与静态变量
protected: // 14. protected 成员变量与静态变量
public:    // 15. public 成员变量 (极力避免直接暴露数据)
           // 16. UE5 虚函数重写 (如 GetLifetimeReplicatedProps，紧随对应访问区)
};
```
- **内联控制**：全面取消 `.inl` 文件；复杂函数在类外定义（同在 `.h` 头文件）。
- **文件后缀**：`.h` 声明与模板；`.cpp` 实现；**严禁使用 `.hpp`**。

## 5. 接口设计规范 (UINTERFACE)

UE5 接口强制使用 `UINTERFACE` + `I` 前缀双结构：

```cpp
// U 类用于反射元数据传递
UINTERFACE(MinimalAPI, Blueprintable)
class UFlexiBagFeatureInterface : public UInterface {
    GENERATED_BODY()
};

// I 类包含纯 C++ 虚析构与接口纯虚/原生事件声明
class FLEXIINVENTORY_API IFlexiBagFeatureInterface {
    GENERATED_BODY()
public:
    virtual ~IFlexiBagFeatureInterface() = default; // 强制虚析构

    UFUNCTION(BlueprintNativeEvent, BlueprintCallable)
    void InitializeFeature(UFlexiBagMainWidget* MainBagWidget);
};
```
- 外部转换统一使用 `Cast<IFlexiBagFeatureInterface>(TargetObject)` 进行多态判定。
