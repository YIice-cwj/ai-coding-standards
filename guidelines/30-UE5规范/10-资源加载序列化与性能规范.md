## 1. 资源引用与异步加载

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-ASSET-REF]** | MUST | 常驻且体积小的资源用硬引用；大资源、可选资源、按需资源使用 `TSoftObjectPtr`/`FSoftObjectPath` | 在 DataTable/配置中硬引用全部大资源；用硬引用加载整包可选内容 |
| **[R-UE-ASSET-ASYNC]** | MUST | 大资源使用 `UAssetManager`/`FStreamableManager::RequestAsyncLoad` 异步加载；持有 `FStreamableHandle` 并在销毁时取消/释放 | 在游戏线程对大资源同步 `LoadObject`；发起异步加载却不持有句柄 |
| **[R-UE-ASSET-LIFE]** | MUST | 异步回调校验对象有效性；组件销毁时取消加载；加载失败有降级资源与日志 | 回调访问已销毁对象；加载失败静默；句柄泄漏 |
| **[R-UE-ASSET-BUDGET]** | MUST | 建立资源体积/数量预算；纹理与音频使用合适压缩/LOD；禁止重复资源 | 无预算引入超大贴图/音频；重复导入同一资源；不做 LOD |

```cpp
void UMyWidget::LoadIconAsync() {
    const FSoftObjectPath IconPath(TEXT("/Game/UI/Icons/Icon_Sword"));
    IconHandle = UAssetManager::GetStreamableManager().RequestAsyncLoad(
        IconPath,
        FStreamableDelegate::CreateUObject(this, &UMyWidget::OnIconLoaded)
    );
}
```

## 2. SaveGame 与序列化

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-SAVE-VERSION]** | MUST | `USaveGame` 包含显式版本号；加载后按版本迁移；可存档字段标 `UPROPERTY(SaveGame)` | 无版本字段；版本升级后直接读旧档导致错位；用裸指针/临时对象存储存档数据 |
| **[R-UE-SAVE-ATOMIC]** | MUST | 写存档采用临时文件 + 原子替换/备份；失败可恢复；大存档异步写 | 直接覆盖正式存档；写入中断导致存档损坏；无备份 |
| **[R-UE-SERIAL-SAFE]** | MUST | 反序列化校验版本、字段范围与类型；不可信数据不进入原生对象反序列化 | 反序列化外部二进制不校验；信任存档中的对象引用与大小 |

```cpp
UCLASS()
class UMySaveGame : public USaveGame {
    GENERATED_BODY()

public:
    UPROPERTY(SaveGame)
    int32 SaveVersion{2};

    UPROPERTY(SaveGame)
    TArray<FName> UnlockedLevels;
};
```

## 3. 性能度量与预算

| 规则标识 | 约束级别 | 强制行为 (DO) | 严禁行为 (DON'T / 一票打回) |
|---|:---:|---|---|
| **[R-UE-PERF-STAT]** | MUST | 使用 `stat unit`/`stat game`/`stat gpu`/`stat memory` 与 Unreal Insights 建立基线；先测量后优化 | 凭感觉优化；只看帧率不看 Game/GPU/Draw 分项；无基线宣称提升 |
| **[R-UE-PERF-TICK]** | MUST | Actor/Component 默认关闭 Tick；用定时器、事件、委托驱动；Tick 内禁止重逻辑 | 默认可 Tick 的空转组件；Tick 内同步加载/大量分配/字符串拼接 |
| **[R-UE-PERF-HOT]** | MUST | 热路径减少分配、锁、日志与虚调用；使用对象池与批量处理；异步加载设并发预算 | 高频循环内 `NewObject`/`UE_LOG`/加锁；无界缓存与队列 |
| **[R-UE-PERF-GPU]** | MUST | 控制 Draw Call、Overdraw、阴影与材质复杂度；使用 LOD/合批/剔除；用 `ProfileGPU` 验证 | 无上限的动态阴影与半透明；全屏 Overdraw；无 LOD 的远景资源 |

AMyActor::AMyActor() {

### 3.1 自动化性能验收与回归

- **SSOT 边界**：性能度量、预算与验收口径的唯一事实源在本文件；[30/07](./07-错误日志测试与构建.md) 只保留功能自动化测试，不重复定义性能口径。
- **自动化计时**：可用 `IMPLEMENT_SIMPLE_AUTOMATION_TEST` 包裹固定样本，以 `FPlatformTime::Seconds()` 采集耗时并断言相对基线；仅在固定关卡、固定设备规格与烘焙包下执行，禁止以编辑器 PIE 数据判定。
- **Insights 采集**：性能结论须附 `-trace=cpu,gpu,frame,bookmark` 的 Insights 记录，或 `stat unit/game/gpu/memory` 前后对比；trace 与构建信息、commit 一并归档。
- **批量设备**：需要多设备/多关卡批次时可使用 Gauntlet（可选，非强制依赖）。
- **门禁强度**：性能回归不作为 PR 硬门禁；改动热路径时必须附基线对比；自动化计时断言默认在专用设备或 nightly 执行。
- **口径回链**：指标分层、环境稳定与证据最小集遵循 [10/03 §5](../10-通用代码规范/03-测试控制流与速查.md#5-性能验证与基准测试-performance-verification--benchmarking)。

## 4. 自检清单

- [ ] 大资源/可选资源使用软引用，常驻小资源才使用硬引用。
- [ ] 异步加载持有句柄，销毁时取消/释放，回调校验对象有效性。
- [ ] 资源体积/数量有预算，纹理/音频压缩与 LOD 已配置。
- [ ] SaveGame 有版本号与迁移逻辑，可存档字段正确标记。
- [ ] 存档写入具备临时文件、原子替换/备份与失败恢复。
- [ ] 反序列化校验版本、类型与范围，不信任外部对象引用。
- [ ] 性能优化基于 `stat`/Insights 基线，Game/GPU/Draw 分项均有数据。
- [ ] 默认关闭无用 Tick，热路径无高频分配、日志与锁。
- [ ] Draw Call、Overdraw、阴影与 LOD 已通过 `ProfileGPU` 验证。
- [ ] 性能结论附 Insights/`stat` 基线或自动化计时对比，并记录构建与设备上下文。
- [ ] 性能回归未作为 PR 硬门禁，自动化性能测试在专用设备或 nightly 执行。
