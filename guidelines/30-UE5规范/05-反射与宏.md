## 1. 反射宏体系与规则约束

| 宏名称 | 核心规则与强制标准 | 严禁行为 (DON'T / 一票打回) |
|---|---|---|
| **`UCLASS(...)`** | 继承 `UObject`；首行必须写 `GENERATED_BODY()` | 遗漏 `GENERATED_BODY()`；尝试修饰模板类 |
| **`USTRUCT(...)`**| 首行必须写 `GENERATED_BODY()`；纯数据结构 | **严禁继承 UObject**（USTRUCT 属于值类型） |
| **`UENUM(...)`**  | 强制修饰 `enum class : uint8` | 修饰裸 `enum`；底层类型非 uint8 |
| **`UPROPERTY(...)`**| 成员指针必须标记以供 GC 跟踪；支持网络同步与 Details 暴露 | 裸指针未标记导致 GC 意外回收崩溃 |
| **`UFUNCTION(...)`**| 暴露蓝图必须指定 `Category = "模块\|子类"`；Pure 函数必加 `const` | 漏设 Category；状态修改函数标 Pure |
| **`GENERATED_BODY()`**| 类/结构体声明体内第一行 | 使用已废弃的 `GENERATED_UCLASS_BODY()` |
| **`#include "*.generated.h"`**| 必须是头文件中**最后一个包含行** | 放在其他包含之前导致 UHT 宏展开链接崩溃 |

## 2. 常用 Specifier 紧凑速查

### 2.1 UPROPERTY 关键修饰符
- **可见性**：`EditDefaultsOnly`（类蓝图默认值编辑）/ `EditAnywhere`（场景实例与类编辑）/ `VisibleAnywhere`（只读查看）。
- **蓝图交互**：`BlueprintReadOnly` / `BlueprintReadWrite`。
- **生命与同步**：`Replicated` / `ReplicatedUsing = OnRep_Xxx` / `Transient`（临时不存档）。
- **常用元数据**：`meta = (ClampMin="0", ClampMax="100", AllowPrivateAccess="true", BindWidget)`。

### 2.2 UFUNCTION 关键修饰符
- **蓝图分类**：`BlueprintCallable` / `BlueprintPure` (必加 `const`) / `BlueprintNativeEvent` (需 `_Implementation`)。
- **网络 RPC**：`Server, Reliable, WithValidation`（客户端发往服务端）/ `Client, Reliable`（服务端发往客户端）/ `NetMulticast`（全网广播）。
