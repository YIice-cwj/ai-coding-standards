## 18. 宏与反射规范

### 18.1 UE5 反射宏家族

| 宏 | 核心规则与约束 | 违规表现 |
|---|---|---|
| `UCLASS(...)` | 类必须继承 `UObject` 或其派生类；体内首行必须写 `GENERATED_BODY()` | 遗漏 GENERATED_BODY() |
| `USTRUCT(...)` | 结构体体内首行必须写 `GENERATED_BODY()`；**严禁继承 UObject** | 继承 UObject 导致编译报错 |
| `UENUM(...)` | 必须修饰 `enum class`；**严禁用于裸 enum** | 修饰裸 enum |
| `UINTERFACE(...)` | 标记接口包装 U 类；与 `I` 前缀接口本体成对出现 | 遗漏 I 接口类 |
| `UPROPERTY(...)` | `UObject*` / `TObjectPtr` 必须标记以供 GC 跟踪；编辑器可见与序列化支持 | 裸指针未标记被 GC 静默回收 |
| `UFUNCTION(...)` | 蓝图可调用函数必须标记并指定 `Category = "模块\|子类"` | 漏设 Category |
| `GENERATED_BODY()` | 必须在类/结构体体内第一行；**禁止使用废弃的 `GENERATED_UCLASS_BODY()`** | 使用旧版废弃宏 |

### 18.2 `.generated.h` 包含铁律
参与反射的头文件**最后一行必须是 `#include "当前文件名.generated.h"`**，否则引发严重链接错误（`unresolved external symbol Z_Construct...`）。

## 附录 A：UPROPERTY Specifier 速查

| 分类 | 常用 Specifier | 作用 |
|---|---|---|
| **可见性** | `EditAnywhere` / `EditDefaultsOnly` / `EditInstanceOnly` | 实例与蓝图类默认值的编辑权限控制 |
| | `VisibleAnywhere` / `VisibleDefaultsOnly` / `VisibleInstanceOnly` | 只读可见性控制 |
| **蓝图访问** | `BlueprintReadWrite` / `BlueprintReadOnly` | 蓝图图表读写权限 |
| | `BlueprintAssignable` / `BlueprintCallable` | 委托绑定与调用权限 |
| **网络同步** | `Replicated` / `ReplicatedUsing = OnRep_Xxx` | 属性网络同步与回调绑定 |
| **生命序列化** | `Transient` / `SaveGame` / `DuplicateTransient` | 临时不保存 / 存档标记 / 复制时跳过 |
| **常用元数据** | `meta = (ClampMin="0", ClampMax="100", AllowPrivateAccess="true", BindWidget)` | 范围限制 / 私有蓝图暴露 / UMG 控件绑定 |

## 附录 B：UFUNCTION Specifier 速查

| 分类 | Specifier | 作用 |
|---|---|---|
| **蓝图类型** | `BlueprintCallable` | 蓝图图表中作为执行节点调用 |
| | `BlueprintPure` | 无副作用查询节点（**必须同时声明 const**） |
| | `BlueprintNativeEvent` | C++ 提供默认实现（需 `_Implementation`），蓝图可覆盖 |
| | `BlueprintImplementableEvent` | 纯蓝图实现，C++ 端无实现 |
| **网络 RPC** | `Server, Reliable/Unreliable, WithValidation` | 客户端发往服务端（配合 `_Validate` 与 `_Implementation`） |
| | `Client, Reliable/Unreliable` | 服务端发往指定客户端 |
| | `NetMulticast, Reliable/Unreliable` | 服务端广播给所有客户端 |
| **辅助说明** | `Category = "模块\|子类"`, `DisplayName = "..."`, `CallInEditor` | 分类展示 / 编辑器重命名 / 细节面板测试按钮 |
